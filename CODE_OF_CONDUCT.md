# Code of conduct

We want this project to be a place where people can ask questions, report bugs and send patches without being treated badly.

**Expected:** be respectful and patient, assume good faith, give and accept feedback graciously, and keep discussion about the work.

**Not acceptable:** harassment, insults, discrimination, personal attacks, publishing other people's private information, or
sustained disruption of discussions.

SkyLostTRs may edit or remove comments, issues and contributions that break these rules, and may block people who repeatedly do.

To report a problem, contact the SkyLostTRs through the address on their GitHub profile, or use a private security advisory if it
also involves a vulnerability. Reports are handled privately.

This document is a short summary in the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), which applies where this text is silent.
